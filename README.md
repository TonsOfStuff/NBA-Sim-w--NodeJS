# NBA Simulation w/ Node JS
NBA Simulation of modern and past players. Review stats, simulate seasons, and watch as the NBA progresses. 

Made to satiate my interest in basketball and data analysis of real life players.
Usable to predict what a new team looks like after a large trade


## Stack
Made with NodeJS and MySQL and stats inspired from NBA 2K.

Link to app: https://nba-sim-w-node-js.vercel.app/
